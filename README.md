1) What is the difference between null and undefined?

Answer: null হইতেছে ভ্যারিয়েবলটি খালি বা কোন value ইচ্ছাকৃতভাবে দেওয়া নেই। আর undefined হইছে যে ভ্যারিয়েবলটি ডিক্লেয়ার করা আছে কিন্তু কোন value দেওয়া হয়নি।

2) What is the use of the map() function in JavaScript? How is it different from forEach()?

Answer: map() হইতেছে যে একটা array থেকে অন্য array তে পরিবর্তন করে নতুন করে। আর forEach হইতেছে Loop এর কাজ করে। 

3) What is the difference between == and ===?

Answer: "==" হইতেছে যে value দেখে type ধরে না। "===" হইতেছে যে value দেখে type দইটিধরে।
